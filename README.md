## 📈 Big Mart Sales Prediction

**Notebook:** `Big_Mart.ipynb` · **Data:** `train.csv` (Big Mart sales dataset)

Retail chains need to know how much of each product an outlet will sell to plan inventory and promotions. This notebook predicts item sales from attributes such as product type, item visibility and MRP, and outlet size, type and location.

**What it covers**
- Data cleaning: handling missing values and inconsistent category labels
- Exploratory data analysis with Matplotlib and Seaborn to find the drivers of sales
- Feature engineering and encoding of categorical variables
- Training and evaluating regression models with Scikit-learn

## ✅ To-Do List Application

**Notebook:** `ToDo_List_Application_with_IO.ipynb`

A command-line task manager written in Python: add tasks, remove them, mark them as completed, and save / load the list with file I/O so tasks persist between runs.
